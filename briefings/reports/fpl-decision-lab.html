4. Forecast architecture and walk-forward validation

The empirical panel is strictly GW1–8 of 2026/27. No previous-season player performance is used. Each completed Gameweek sequentially updates minutes, starts, xG, xA, clean sheets, saves, bonus, cards, defensive contributions and realised points. Sparse player rates are shrunk toward current-season positional medians using a weak 360-minute pseudo-sample:

posterior rate = (minutes × observed rate + 360 × current-season positional rate) / (minutes + 360)

The event/state model first defines expected minutes, start/appearance states, official fixture difficulty, home advantage, scoring components and clean-sheet states. Current evidence creates separate mixtures for Fernandes’ selection, Wissa’s role, João Pedro’s confirmed absence and the three 75% defenders. Only after that generative model is fixed do 20,000 common-random-number simulations draw appearance states, shared team shocks and over-dispersed points. Each draw enforces legal formations, ordered autosubs and captain/vice fallback. Ordinary bench points are never added to XI expectation.

  • Aleatoric uncertainty: match outcomes, scoring, clean sheets and bonus.
  • State uncertainty: starts, minutes, injury/role persistence, captain fallback and autosubs.
  • Epistemic uncertainty: only eight completed rounds, weak priors and model specification.
