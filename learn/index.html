Add a YouTube API key once

The picker needs a YouTube Data API key to retrieve and score real videos. The key is stored only in this browser and is never committed to GitHub.

  1. Create or choose a Google Cloud project.
  2. Enable YouTube Data API v3.
  3. Create an API key and restrict it to this website’s HTTP referrer.
  4. Paste it below.
